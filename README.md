# 3人対戦じゃんけん（決勝つき・3ポイント先取）

あなた・相手1・相手2の3人でじゃんけんをして、先に3ポイント取った人が優勝するブラウザゲームです。
勝ちが2人のときは、その2人で決勝じゃんけんをして勝者を1人に決めます。

## あそびかた

1. `index.html` をブラウザで開きます
2. 「グー」「チョキ」「パー」のボタンから手を選びます
3. 「じゃん・けん・ぽん！」で3人の手が出て、勝ち負けが決まります
4. 勝者が1人に決まると、その人に +1ポイント入ります
5. 誰かが3ポイント取ったらゲーム終了です。ランキングが出るので「もう一度あそぶ」で再挑戦できます

## ルール

1回戦の流れは次のとおりです。

```
予選（3人でじゃんけん）
 ├─ あいこ（全員同じ手／全員バラバラ）→ 3人で「あいこでしょ！」
 ├─ 勝ちが1人 → その人が +1ポイント
 └─ 勝ちが2人 → 負けた1人は敗退、勝った2人で決勝へ
       決勝（2人でじゃんけん）
        ├─ あいこ → 2人で「あいこでしょ！」
        └─ 勝ち → その人が +1ポイント
```

- ポイントがもらえるのは、その回戦の最後に残った1人だけです（負けてもマイナスにはなりません）
- 1回戦ごとに、必ず誰か1人が +1ポイントになります
- 3ポイント取った人が出たら、その時点でゲーム終了です
- あなたが予選で敗退したときは、相手どうしの決勝が自動で進みます（ボタンは押せなくなります）

## 画面の見かた

- **第◯回戦 予選（3人）／決勝（2人）**：今どの段階かを表します。決勝になると赤く光ります
- **カードのポイント表示とゲージ**：今のポイントと、3ポイントまでどれくらいかを表します
- **バッジ**：「WIN +1」「LOSE」「あいこ」「決勝へ」「敗退」が出ます
- **敗退したカード**：決勝に進めなかった人はグレーで小さく表示されます
- **+1**：勝者が決まると、カードの上に浮かんで出ます
- **履歴**：直近8件の勝負（それぞれの手と結果）が新しい順に出ます

## しくみ（js/test.js）

じゃんけんに参加している人を配列 `active` で管理しています。
予選では `[0, 1, 2]`（3人）、決勝では勝った2人だけ（例：`[0, 2]`）になります。

| 関数 | やっていること |
| --- | --- |
| `janken(me)` | ボタンを押したときに呼ばれます。あなたが参加中なら `play()` を呼びます |
| `play(me)` | 参加している人の手を決めて「じゃん・けん・ぽん」を表示します |
| `show(hands)` | 手を見せて、あいこ／勝ち2人／勝ち1人を判定します |
| `onDraw()` | あいこのとき。同じメンバーでもう一度じゃんけんします |
| `onFinal(winners)` | 勝ちが2人のとき。負けた人を敗退にして、2人で決勝にします |
| `onWinner(winner)` | 勝者が1人に決まったとき。+1ポイントして、3ポイントなら終了します |
| `next()` | 次のじゃんけんの準備。あなたが敗退していたら相手どうしの決勝を自動で進めます |
| `loseToOf(hand)` | その手が負ける手を返します（グー→パー など） |
| `showResult(winner)` | 結果画面（ランキング）を表示します |
| `resetGame()` | ゲームを最初の状態に戻します |

あいこの判定は「出た手の種類の数」で行っています。1種類（全員同じ）か3種類（全部バラバラ）ならあいこです。2人の決勝では、手の種類が1種類のときだけあいこになります。

## 調整のしかた

優勝に必要なポイントは、`js/test.js` の先頭にある数字で変えられます。

```js
var GOAL = 3; // 3ポイント取ったら優勝
```

変えたときは、`index.html` のルール説明（「3ポイント先取で優勝」）も合わせて直してください。
